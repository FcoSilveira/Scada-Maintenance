# Scada-Maintenance
Scada-Maintenance é uma coleção de ferramentas para manutenção, auditoria e automação de projetos SCADA, com foco em ScadaBR e Scada-LTS. Inclui utilitários para análise de JSON, validação de configurações, geração de relatórios e otimização de rotinas de engenharia e comissionamento.
